# abapGit simplification suggestions

This file records narrowly scoped changes that would make abapGit easier to
reuse independently of HitHub. HitHub milestones never depend on upstream
acceptance; each suggestion keeps a local fallback.

Copy the template below for each suggestion. Resolved and declined entries
remain as project history.
